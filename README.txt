ACTIVITY SWITCHER — Windows

Запуск: ActivitySwitcher.exe. Установка и Python не нужны.
Нужен .NET Framework 4.8 (обычно уже есть в Windows 10/11).

ПЕРВЫЙ ЗАПУСК
1. Открой настольный Discord и войди в аккаунт.
2. Перейди на https://discord.com/developers/applications
3. Нажми New Application, задай название и создай приложение.
4. В General Information скопируй Application ID в Activity Switcher.
   Это публичный числовой ID. Токен аккаунта, Bot Token и Client Secret не нужны.
5. Выбери .exe или ярлык .lnk кнопкой «…» либо перетащи файл в окно.
6. Укажи название активности, при желании описание и вторую строку.
7. Нажми «Включить».

КАК РАБОТАЕТ
- Пресет «VS Code · Overflow» заполняет название Visual Studio Code
  и описание «Проект: Overflow», а также ссылку на официальную иконку VS Code.
  Это заданный вручную текст; он не проверяет,
  какой проект открыт в редакторе, и не создаёт папку или проект Overflow.
  Code.exe ищется в стандартных папках установки. Если он не найден,
  пресет включает ручной режим; можно выбрать Code.exe самостоятельно.
- По умолчанию карточка появляется, пока выбранный EXE запущен.
- Программа сама не запускает выбранный файл.
- Если выключить проверку запущенной программы, карточка показывается
  постоянно, пока Activity Switcher работает и включён.
- Выбор файла подставляет его имя в поле названия. Название можно изменить.
- Поддерживаются .exe и обычные Windows-ярлыки .lnk, ведущие к .exe.
  Интернет-ярлыки .url и специальные ярлыки приложений не поддерживаются.
- Для лаунчера выбери конечный EXE игры: процесс лаунчера может завершиться
  сразу после запуска игры. Проверяется точный путь, а не только имя процесса.
- Для картинки можно указать HTTPS-ссылку на доступное изображение.
  В пресете используется https://raw.githubusercontent.com/microsoft/vscode/main/resources/linux/code.png
  Если Discord не загрузит внешнюю картинку, загрузи её в своё приложение:
  Developer Portal → Rich Presence → Art Assets, затем вставь ключ картинки
  в поле программы. Иконку по ссылке загружает Discord.
  Иконка выбранного EXE автоматически в Discord не загружается.
- Кнопка «Остановить» убирает только карточку этой программы.
- Закрытие окна разрывает RPC-соединение; Discord может убрать карточку
  с небольшой задержкой.
- Настройки сохраняются после нажатия «Включить» в
  %LOCALAPPDATA%\ActivitySwitcher\settings.json. При запуске активность
  автоматически не включается. Автозагрузка не настраивается.

ОГРАНИЧЕНИЯ
Программа создаёт собственную Rich Presence через локальный Discord RPC.
Она не может принудительно удалять, блокировать или заменять карточки,
которые отправляют Real, Roblox или другие приложения. Отключи Discord RPC
в этих приложениях, если нужна только одна карточка.
Общий запрет показа активности в Discord скрывает и эту карточку.
Видимость другим пользователям зависит от настроек Discord.
Современный Discord поддерживает поле name; если клиент показывает имя
приложения из Developer Portal, переименуй там своё приложение.

ПРОВЕРКА СБОРКИ
Проверено на отдельном тестовом named pipe: подключение и READY,
SET_ACTIVITY с названием и русским текстом, очистка activity=null,
PING/PONG, фрагментированные пакеты, ошибки RPC и разрыв соединения.
Проверены .lnk, точный путь запущенного процесса и отрисовка окна.
Проверка с настоящим Discord не выполнена: нужен твой Application ID.

ИСХОДНИКИ
ActivitySwitcher.cs — полный исходный код на C#.
build.ps1 — сборка средствами .NET Framework, без скачивания пакетов.
Программа соединяется только с локальным named pipe Discord, не читает
токены и сообщения. Внешний сайт открывается только по кнопке «Где взять ID?».
Внешняя ссылка на изображение передаётся Discord в данных активности.
Тексты карточки передаются Discord и могут быть видны другим пользователям.
